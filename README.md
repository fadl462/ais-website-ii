# AIS NEXUS — Prototype 2

A motion-led, editorial-style school website prototype based directly on the supplied **Prototype 2 — AIS NEXUS** brief.

## Core direction
- Premium "digital campus" rather than conventional school website
- AIS palette: Navy `#071A3D`, Orange `#F36B16`, White, Ice `#F5F7FA`, Deep Ink `#0B1220`
- Oversized typography, asymmetrical editorial compositions, cinematic photography
- Purposeful motion and responsive interaction

## Interaction highlights
- Shrinking floating command bar on scroll
- Full-screen menu overlay
- Cinematic hero with floating admissions card
- Scroll-responsive hero background
- Animated AIS statement line
- Interactive AIS Journey stages
- Interactive academic stage imagery
- Full-viewport "Why AIS?" background image switching
- Staggered School Life media tiles
- Dynamic facilities image + copy selector
- Admissions journey conversion block
- Live AIS feed presentation
- Stories/content engine
- AIS Now / AIS Next split-screen
- Reduced-motion support

## Run
Open `index.html` in a browser. No build step is required.
Internet access is needed for the Google Fonts and remote Unsplash photography used in this prototype.
